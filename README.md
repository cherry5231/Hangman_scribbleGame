# Hangman Game (Single Player)

A modern **Hangman** game built with **Python** and **Flask**, featuring a clean UI, animated ASCII art, hints, sound effects, and a large collection of words from different categories.

---

##  Features

*  Single-player Hangman gameplay
*  Built-in hints for every word
*  Modern responsive interface
*  Animated ASCII hangman
*  Sound effects for correct, wrong, win, and game over
*  Restart game anytime
*  100+ words from multiple categories:

  * Superheroes
  * Games
  * Technology
  * Animals
  * Countries
  * Science
  * Anime
  * Movies
  * Mythology
  * And more!

## How to Play

1. Start a new game.
2. Guess one letter at a time.
3. Use the hint if you get stuck.
4. Every incorrect guess reduces your remaining attempts.
5. Guess the complete word before the hangman is completed.
